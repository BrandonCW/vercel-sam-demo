1. Single Workflow Tool Architecture Exemplary (10/10) agent/tools/run_assessment.ts
agent/instructions.md		 Instead of giving an LLM 10 separate tools and hoping it reasons through them without hallucinations, Eve encourages sequencing complex multi-turn workflows in code via a single tool generator (`run_assessment`). The root LLM stays compact (~200 tokens input).
2. Zero-Compute HITL Workflow Suspend (`ctx.ask`) Exemplary (10/10) agent/tools/run_assessment.ts:61-62 Idiomatic use of `ctx.ask()` to park the workflow while waiting for SA discovery input. Zero CPU, zero token consumption during human wait time (configured for up to 30 days via `sessionTimeoutMs`).
3. Two-Tier Streaming Contract (`action.partial`) Exemplary (9.5/10) agent/tools/run_assessment.ts
lib/assessment-results.ts		 Tool yields 4 intermediate states over NDJSON (`jev_scored`, `jev_saved`, `system2_saved`, `feedback_recorded`). Client's `assessmentReducer` updates UI in real time rather than freezing on a 36-second loading spinner.
4. Concurrency & Replay Safety (`"use step"`) Exemplary (9.5/10) agent/lib/assessment-steps.ts
lib/db/crm.ts		 Every side-effecting operation in the workflow uses `"use step"` for checkpointing and idempotency. Paired with Postgres transaction-level advisory locks (`pg_advisory_xact_lock`) and optimistic `ae_notes` verification.
5. Context Footprint Management (`toModelOutput`) Exemplary (9.5/10) agent/tools/run_assessment.ts:75-94 Tool returns full rich `AssessmentResult` to the client via `action.result`, but defines a `toModelOutput` projection that passes only a compact summary (scores, delta, status) back to the root LLM, slashing turn 2 root context cost by 97%.
6. Edge Route Handler & Auth Bridge (`withEve()`) Minor Gap (7.5/10) next.config.ts
lib/eve-auth.ts
middleware.ts		 Correctly wraps `next.config.ts` with `withEve()`, but auth chain in `lib/eve-auth.ts` checks `dealQualSessionAuth` before `localDev()`, throwing 500 errors if an expired cookie exists in local dev without `APP_PASSWORD` configured.
7. Workflow Cancellation & Abort Propagation Critical Gap (4/10) agent/tools/run_assessment.ts
lib/assessment-results.ts		 UI wires `agent.cancel()` to the Abort button, but `ctx.abortSignal` is never passed to `scoreWithJev` or `analyzeWithSystem2`, and `assessmentReducer` ignores `turn.cancelled`. Clicking Abort freezes the UI spinner while backend AI calls keep burning tokens.
8. Live E2E Evals (`defineEval` / `eve/evals`) Exemplary (9.5/10) evals/evals.config.ts
evals/acme/assess-then-qualify.eval.ts		 Tests real multi-turn workflow pausing (`session.requireInputRequest` → `session.respond`), DB state assertions, and LLM judge checks coordinated by a Postgres advisory lease (`live_run_lease`).
